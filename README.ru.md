Только данные, бэктест и виртуальные сделки: **никаких реальных ордеров, кошелька и ключей**.

| Папка | Что там |
|---|---|

## Бот бумажной торговли (`paper/`)

**Правило** (зафиксировано по бэктесту, не подстраивать):
1. ≥ 2 кошелька из топ-50 по киберспорту **вошли** в один исход за 6 ч, **до начала матча**.
   Сравнение: «1 кошелёк из топ-50» (k1) и «2 кошелька из топ-100» (k2t100, добавлено 8 ноября 2026).
2. Через 60 с ставится виртуальная лимитка: цена смартов + 1¢, живёт 5 минут и должна истечь до старта матча.
3. Исполнение засчитывается, только если по публичной ленте за эти 5 минут прошли сделки по нашей цене или лучше. Ставка — min($100, 50% этого объёма), комиссия 1%.
4. Позиция держится до итога матча.

Параллельно бот записывает стакан и считает эксперимент **«купить сразу»**: до $100 по аску, не дороже цены смартов + 2¢.

**Результаты:** откройте `paper/report.html` в браузере. Страница обновляется сама каждые 2 минуты. Цель — 200 закрытых сделок (примерно 2–3 месяца). Ориентир из бэктеста: около +6% на оборот, 50–100 исполнений в месяц.

**Файлы:**
- `bot.py` — сам бот;
- `report.py` — страница с результатами;
- `paper.db` — все сигналы и сделки (SQLite);
- `logs/bot.log` — журнал;
- `wallets/YYYY-MM.csv` — топ-100 кошельков на месяц (правила k2/k1 берут первые 50).

### Управление
Бот запускается автоматически (LaunchAgent `com.polymarket-research.paper`) при входе в систему и перезапускается при падении.

Остановить:
```bash
launchctl bootout gui/$(id -u)/com.polymarket-research.paper
```

Запустить снова:
```bash
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.polymarket-research.paper.plist
```

Удалить автозапуск совсем:
```bash
launchctl bootout gui/$(id -u)/com.polymarket-research.paper; rm ~/Library/LaunchAgents/com.polymarket-research.paper.plist
```

### Важно
- **Mac не должен спать.** Бот держит его бодрствующим (`caffeinate`), но закрытая крышка MacBook без внешнего монитора всё равно усыпляет компьютер. Сигналы за это время пропадут: бот запишет их как «найден поздно» и не будет по ним торговать.
- **Список кошельков нужно обновлять раз в месяц.** Сейчас есть только `wallets/2026-11.csv`. С 1 декабря бот продолжит работать со старым списком, а на странице появится предупреждение. Обновление — это пересчёт скоринга на свежих данных. Его делает Claude по коду из `research/`.
